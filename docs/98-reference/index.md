本部分提供 Svelte 完整的 API 参考，涵盖 `svelte` 主模块及其子模块导出的函数、类与类型，以及编译器与运行时的错误、警告说明。

## 模块

- [svelte](/docs/svelte)：核心模块，导出最常用的运行时 API
- [svelte/action](/docs/svelte-action)：可复用的 DOM 行为
- [svelte/animate](/docs/svelte-animate)：列表动画辅助函数
- [svelte/attachments](/docs/svelte-attachments)：元素附加行为
- [svelte/compiler](/docs/svelte-compiler)：编译相关 API
- [svelte/easing](/docs/svelte-easing)：动画缓动函数
- [svelte/events](/docs/svelte-events)：事件辅助函数
- [svelte/legacy](/docs/svelte-legacy)：从旧版本迁移的兼容 API
- [svelte/motion](/docs/svelte-motion)：运动/过渡相关 API
- [svelte/renderer](/docs/svelte-renderer)：自定义渲染器 API
- [svelte/reactivity](/docs/svelte-reactivity)：响应式工具
- [svelte/reactivity/window](/docs/svelte-reactivity-window)：与 window 相关的响应式状态
- [svelte/server](/docs/svelte-server)：服务端渲染相关 API
- [svelte/store](/docs/svelte-store)：状态存储
- [svelte/transition](/docs/svelte-transition)：过渡动画
