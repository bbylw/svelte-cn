```svelte
<!--- copy: false  --->
{#if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else if expression}...{/if}
```

```svelte
<!--- copy: false  --->
{#if expression}...{:else}...{/if}
```

条件渲染的内容可以用 if 块包裹起来。

```svelte
{#if answer === 42}
	<p>what was the question?</p>
{/if}
```

可以通过 `{:else if expression}` 添加额外条件，并可选地以 `{:else}` 子句结尾。

```svelte
{#if porridge.temperature > 100}
	<p>too hot!</p>
{:else if 80 > porridge.temperature}
	<p>too cold!</p>
{:else}
	<p>just right!</p>
{/if}
```

（代码块不一定要包裹元素，也可以包裹元素内部的文本。）
